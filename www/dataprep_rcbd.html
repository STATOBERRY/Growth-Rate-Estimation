Instruction Manual for Data Preparation

1. Overview

RAISINS allows for analyzing multiple characters simultaneously. So you can enter the observations for all characters for a particular set of subjects in a single excel file.

This is a one-way repeated measures ANOVA, so the same subjects (experimental units such as plots, animals, or patients) are measured repeatedly across several days/time points. There is a single within-subject factor – the Day/Time – and each subject is measured once at every day.

2. Creating a Data File in MS Excel

  • Open a new microsoft excel file, use single sheet only.
  • Start with Cell A1: Open a new MS Excel file and begin entering data from cell A1. Do not leave any blank rows above.
  • First Row - Column Names: The first row must contain the column names.
    • Column 1: should be Subject (identifies each experimental unit that is measured repeatedly)
    • Column 2: should be Day/Time (the repeated measurement occasion)
    • From Column 3 Onwards: Enter the names of each character under study as separate columns (e.g., char1, char2, char3). You can give any names to the subject, day, and character columns.

4. File Format Recommendation

  • You can upload the .xls format (excel file itself) directly. If your data file large we may also recommend a .csv format for smooth data handling.

5. Naming Columns

  • Keep It Simple and Straight (KISS): Use simple and short names for column headers.
  • Avoid Complexity: Do not include units, special characters, or spaces in names (e.g., use char1 instead of Character 1).
  • This helps ensure the names appear neatly in plots and outputs.

6. Creating Data Using the App (Recommended Method)

  • Navigate to "Create Data" Tab: Click on the Create Dataset tab in the main menu at the top of the app.
  • Specify Details: Enter the number of subjects, days/time points, and number of characters under study in the window that opens. Then click create.
  • Model Data Entry File: A template for data entry will be generated. You can:
    • Directly enter your data into this template.
    • Or, copy-paste data from an existing Excel file.
  • Download as CSV: Once the data is entered, click on the Download CSV File button. The downloaded CSV file can be uploaded for analysis in Analysis tab.

Image below shows the window of Create Data tab

7. Uploading the Data File for Analysis

  • Upload the Prepared CSV/XLS File: Go to the Analysis tab and upload your prepared data file, then select the Subject column and the Day/Time column along with the characters to analyse.
  • Ensure Clean Data: Keep the file focused on the data; avoid adding any extra information or notes outside the data area.

By following these instructions, you will have a well-prepared data file ready for analysis, allowing you to process multiple characters together.
