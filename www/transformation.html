Transformation Algorithms Used in RAISINS Repeated Measures ANOVA (One Way)

To aid researchers in analyzing their data, RAISINS Repeated Measures ANOVA (One Way) provides three types of transformations: Log Transformation, Square-root Transformation, and Arcsin Transformation. Each transformation has unique criteria to ensure appropriate application. Below is a detailed breakdown of how each transformation operates:

1. Log Transformation

The log transformation is used to reduce skewness and stabilize variance in quantitative variables. The transformation is applied column-wise based on the presence of zero or negative values, as described below:

  • Columns Containing Zero or Negative Values (≤ 0):
    If any value in the selected column is less than or equal to zero, a data-dependent shift is applied before transformation. The minimum value (min_val) of the column is first identified, and all observations are shifted to ensure positivity: 
    log10(x − min_val + 1)
    This guarantees that the smallest transformed value becomes 1, making the log transformation mathematically valid.
  • Columns with All Positive Values (> 0):
    If all values in the column are already positive, the base-10 logarithm is applied directly without any adjustment: 
    log10(x)

This adaptive approach ensures numerical stability while preserving the relative structure of the original data.

2. Square-root Transformation

This transformation is typically used to reduce positive skewness in the data. The logic behind this transformation is as follows:

  • All Positive Values: If all values in the selected column are positive, the square root transformation is applied directly: 
    sqrt(x)
  • Any Zeros: If any values in the column are zero, 0.5 is added to all values before taking the square root to prevent undefined results: 
    sqrt(x + 0.5)
  • Any Negative Values: If the column contains negative values, no transformation is applied, and a warning is displayed to notify the user.

3. Arcsin Transformation

The Arcsin transformation is specifically used for proportion data (values between 0 and 1). This transformation is applied as follows:

  • All Values Between 0 and 1: If all values in the selected column are between 0 and 1, the arcsin square root transformation is applied: 
    asin(sqrt(x))
  • Handling 0 and 1 Values: If any values are exactly 0 or 1, they are adjusted as follows before applying the arcsin transformation:
    • Values of 0 are replaced with 1 / (4 * n), where n is the total number of observations.
    • Values of 1 are replaced with 1 - 1 / (4 * n).
    asin(sqrt(x))
  • Values Outside [0, 1] Range: If the data contains values outside the [0, 1] range, no transformation is applied, and a warning is displayed. In such cases, it is recommended to convert the data to proportions before applying the transformation.

These transformations provide a robust approach to making data suitable for analysis. For optimal results, consult a statistician to determine the most appropriate transformation based on your data.
