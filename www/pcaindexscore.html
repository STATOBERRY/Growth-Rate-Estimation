Construction of Index Scores Based on PCA

1. Standardization of Variables

In RAISINS, the uploaded variables are standardized to ensure that each variable has a mean of zero and a standard deviation of one. If X be the original data matrix of size \(n \times p\), where:

n: number of observations (e.g., treatments)

p: number of variables (e.g., traits under study)

To ensure all variables contribute equally, standardize the matrix X by subtracting the mean and dividing by the standard deviation for each variable:

\[ Z_{ij} = \frac{X_{ij} - \mu_j}{\sigma_j}, i=1,2,...,n; j=1,2,...,p \]

where:

  • \(X_{ij}\): The value of the \(j^{th}\) variable for the \(i^{th}\) treatment / observation (original value).
  • \(\mu_j\): The mean of the \(j^{th}\) variable.
  • \(\sigma_j\): The standard deviation of the \(j^{th}\) variable.

This produces the standardized data matrix Z (size \(n \times p\)).

2. PCA Computation

PCA is based on the Singular Value Decomposition (SVD) of the standardized data matrix \(Z\). The matrix \(Z\) is standardized such that each column (representing variables) has zero mean and unit variance. Let \(Z\) be of size \(n \times p\), where \(n\) is the number of observations (treatments) and \(p\) is the number of variables (characters under study).

The decomposition is:

\[ Z = U \times S \times V^T \]

where:

  • \(U\): An \(n \times p\) orthogonal matrix containing the principal component scores.
  • \(S\): Diagonal matrix of singular values (\(n \times p\)).
  • \(V^T\): A \(p \times p\) orthogonal matrix containing the principal component loadings.

3. Relationship Between Scores and Loadings

The scores for each principal component are calculated as:

\[ U_k = Z v_k \]

where:

  • \(v_k\): The eigenvector corresponding to the \(k^{th}\) principal component (column \(k\) of \(V\)).
  • \(U_k\): The \(k^{th}\) column of \(U\), containing the scores for the \(k^{th}\) principal component.

For \(PC_1\), we extract \(v_1\) and compute:

\[ u_{i1} = \sum_{j=1}^p z_{ij} \cdot v_{j1} \]

where:

  • \(z_{ij}\): Standardized value of the \(j^{th}\) variable for the \(i^{th}\) treatment.
  • \(v_{j1}\): Loading (eigenvector coefficient) of the \(j^{th}\) variable for \(PC_1\).

4. Interpretation of \(u_{i1}\)

The value \(u_{i1}\) represents the weighted combination of standardized variables (\(z_{ij}\)) for the \(i^{th}\) treatment. The weights are the corresponding loadings (\(v_{j1}\)).

Treatments with higher \(u_{i1}\) scores contribute more to the variance explained by \(PC_1\), while those with lower scores contribute less.

5. Index Score Construction

The raw index scores are derived from the principal component scores:

  • Index 1 (PC1):
    • \[ I_{1i} = u_{i1} \]
  • Index 2 (PC2):
    • \[ I_{2i} = u_{i2} \]

To normalize the indices, min-max scaling is applied:

  • For Index 1:
    • \[ I_{1i} {\text{(scaled)}} = \frac{I_{1i} - \min(I_1)}{\max(I_1) - \min(I_1)} \]
  • For Index 2:
    • \[ I_{2i} {\text{(scaled)}} = \frac{I_{2i} - \min(I_2)}{\max(I_2) - \min(I_2)} \]
